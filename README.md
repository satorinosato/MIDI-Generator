# MIDI-Generator
Небольшая программа на Python, которая сочиняет случайные мелодии по выбранной гамме и сохраняет их в MIDI-файл. Внешние библиотеки не нужны: MIDI записывается вручную средствами стандартной библиотеки.

Возможности
5 гамм: мажор, минор, дорийский лад, пентатоника, блюз
любая тоника (C, C#, D, ... B)
настраиваемые темп и длина (в тактах)
мелодия строится «блужданием» по гамме: чаще соседние ноты, иногда прыжки, случайные паузы и разные длительности нот
мелодия заканчивается на тонике, поэтому звучит завершённо
второй трек с басовой партией по прогрессии I–V–vi–IV
параметр --seed для повторяемости: одно и то же число даёт ту же мелодию
